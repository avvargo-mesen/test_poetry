# Проект "Виджет банковских операций клиента"

## Описание:

Этот проект представляет собой виджет для обработки банковских операций, позволяющий фильтровать и сортировать 
транзакции по определённым критериям.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/avvargo-mesen/test_poetry.git
```
2. Зависимости.

- pandas	 3.0.3
- openpyxl	3.1.5	
- requests	2.33.1
- python-dotenv	1.2.2

3. Требования:

- Python 3.14+
- Poetry

## Использование:

1. Фильтрация по статусу.

Функция filter_by_state(dict_list, state)
Принимает список словарей и опционально значение для ключа 
state, возвращает новый список словарей, где state соответствует указанному значению.

from src.processing import filter_by_state

result = filter_by_state ([{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}], state='EXECUTED')
print(result)


2. Фильтрация по дате.

Функция sort_by_date(dict_list: list, descending)
Принимает список словарей и порядок сортировки, возвращает новый список, отсортированный по дате.

from src.processing import filter_by_state

result = sort_by_date([{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}])
print(result)

Модуль `data_reader.py` содержит функции read_csv_files, read_excel_files.

### `read_csv_files(csv_file_path: str) -> list[dict]`

**Описание:**

Считывает финансовые операции из CSV

**Пример использования:**

Файл должен быть в формате CSV с разделителем `;` и содержать следующие колонки:

| Колонка | Тип | Описание |
|---------|-----|----------|
| id | float | Уникальный идентификатор операции |
| state | string | Статус операции (EXECUTED/CANCELED) |
| date | string | Дата операции в формате ISO |
| amount | float | Сумма операции |
| currency_name | string | Название валюты |
| currency_code | string | Код валюты |
| from | string | Отправитель |
| to | string | Получатель |
| description | string | Описание операции |

Пример вывода данных:

[{'id': 650703.0, 'state': 'EXECUTED', 'date': '2023-09-05T11:30:32Z',
                                              'amount': 16210.0, 'currency_name': 'Sol', 'currency_code': 'PEN',
                                              'from': 'Счет 58803664561298323391', 'to': 'Счет 39745660563456619397',
                                              'description': 'Перевод организации'}]
